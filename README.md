# Battle Cities — Unity releases

Play the game in your browser: **https://cryptosodi.github.io/BattleCitiesUnity-Releases/**

## Downloads

Download the latest Android APK, Windows ZIP, or web ZIP from [Releases](https://github.com/CryptoSodi/BattleCitiesUnity-Releases/releases/latest).

- **Android:** ARM64 APK for Android phones and PSG1. Uses the existing test signing certificate.
- **Windows:** 64-bit build. Extract the complete ZIP and run `BattleCities.exe` with its accompanying files in the same folder.
- **Web:** Play on GitHub Pages or serve the extracted web ZIP over HTTP. Opening `index.html` directly from disk is not supported.

This repository distributes compiled game builds. The Unity source project is maintained separately.

The build files include SHA-256 checksums. The web deployment workflow publishes the web ZIP from a chosen GitHub release.
